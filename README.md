## Overview

Byteware is a lightweight Windows utility designed to give users more control over their system.

It brings together privacy settings, system cleanup, and useful everyday tools in one simple interface. Byteware focuses on simplicity, transparency, and reversible changes without unnecessary modifications to Windows.

The application is distributed as a standalone executable. No source files or additional installation packages are required.

## Features

### System privacy

- Disable unnecessary Windows telemetry and data collection.
- Remove advertising and personalized suggestions.
- Disable unwanted Windows recommendations and promotional content.
- Manage optional Windows features and background activity.
- Reduce unnecessary data collection from supported applications.

### System cleanup

- Remove unnecessary temporary files.
- Clean up unwanted preinstalled applications.
- Manage startup applications.
- Simplify Windows interface settings.
- Apply predefined system optimization presets.

### Utilities

- System information and monitoring.
- Clipboard management.
- Quick access to useful Windows actions.
- Convenient system settings management.

_Available features may vary between versions._

## Requirements

- Windows 10 or Windows 11
- Administrator privileges for system modifications
- Internet connection only for features that require it

## Installation

Byteware does not require a traditional installation process.

1. Download `byteware.zip` from the latest release.
2. Extract the archive.
3. Move the executable to a convenient location.
4. Run it whenever you need it.

Depending on the features used, Byteware may request administrator privileges.

## Usage

1. Launch Byteware.
2. Explore the available tools and settings.
3. Select the features you want to use.
4. Review the changes before applying them.
5. Apply the selected changes.

Some changes may require restarting Windows or the affected application.

## Privacy

Byteware is designed with privacy in mind.

- No user accounts are required.
- No unnecessary analytics or tracking.
- No personal information is intentionally collected.
- Local operations are performed directly on your device.

Features that require external services or network access may communicate with their respective providers.
